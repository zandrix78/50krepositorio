# 50K Restaurante

Este projeto foi unificado em uma única página principal: `index.html`.

- Todos os módulos do sistema agora ficam em um único arquivo HTML.
- As páginas antigas foram convertidas em redirecionamentos para o painel principal.
- A navegação por módulos funciona diretamente no `index.html`.

Para visualizar o sistema localmente, abra o arquivo `index.html` no navegador ou use um servidor simples como:

```bash
python -m http.server 8000
```

Após isso, acesse `http://localhost:8000`.
