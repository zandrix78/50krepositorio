# Sistema de Gestão para Restaurantes

Este projeto é uma base inicial de interface web para um sistema de gestão de restaurante, cobrindo os módulos descritos no escopo do negócio: pedidos, estoque, financeiro, CRM, marketing, WhatsApp, fidelidade, IA, multiunidades e relatórios.

## Estrutura

- `index.html` — layout principal da aplicação
- `styles.css` — estilos da interface
- `script.js` — dados dinâmicos e interações
- `.gitignore` — arquivos locais irrelevantes

## Como executar

Abra o arquivo `index.html` diretamente no navegador ou use um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6

## Observações

Este é um MVP frontend para apresentação e validação visual. O backend e banco de dados podem ser adicionados depois conforme a evolução do projeto.
